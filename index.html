Brick Instructions Tools

Brick Instructions Tools is a set of private Python command-line scripts used by Paul Critchlow, an individual creator, to manage his own YouTube channel Brick Instructions (channel ID UCsBhXt02zj-EmXUQeXUV3Sg).

The scripts use the YouTube Data API (Google Cloud project brick-instructions-titles) to upload around five building-instruction videos per day as private, set their thumbnails, add them to playlists, and bulk-update titles. There is no public user interface and no other users: the tool is operated only by the channel owner on his own channel.

By using this tool you agree to be bound by the YouTube Terms of Service.
