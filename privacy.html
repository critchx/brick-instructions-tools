Who we are

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

With the OAuth scope https://www.googleapis.com/auth/youtube.force-ssl, the scripts access only the owner's own YouTube channel to upload videos (videos.insert), set thumbnails (thumbnails.set), add videos to playlists (playlistItems.insert) and read/update video titles (videos.list, videos.update).

What data is stored

  • Video IDs, titles and timestamps, in local CSV log files.
  • An OAuth token file, so the scripts can act on the owner's behalf.

Both are stored only on the owner's private Linux computer. No data about any other person is collected.

Sharing

No data is shared with, sold to, or disclosed to any third party. No analytics, advertising, tracking or cookies are used, by the tool or by this website.

Legal basis and retention (UK GDPR)

Processing is limited to the owner's own account data, under legitimate interests in managing his own channel. Logs are kept while useful for channel management and deleted on request or when no longer needed; stored API data is refreshed or deleted in line with YouTube API Services policies.

Revoking access

Access granted to this tool can be revoked at any time via the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the local token file also stops all access.

Your rights

Under UK GDPR you may request access, correction or deletion of personal data, or complain to the Information Commissioner's Office (ico.org.uk). Contact indiebrick@gmail.com.
